# RW11用電源通信仕様書 D6 → r1 差分・開発影響確認

確認日: 2026-09-07。仕様移行の実装ではなく、原典比較と現在のPico治具への影響評価。

## 基準移行の追記 2026-09-07

ユーザー指示により、フォルダ内の `reference/RW11用電源通信仕様書r1.pdf` を今後の開発基準へ採用。SHA256は本レビューのr1原典と一致する。AGENTS.md、開発・引継ぎ文書と各Masterの基準参照を更新し、OFF期間の更新条件をDecode/試験文書へ反映した。以下は移行前レビューの記録であり、「基準文書参照の移行」は本追記で完了。既存Issue・実機確認は残る。

## 結論

今回の改訂差分からは、通常通信・Decode・Cache・RTC・SDの開発を停止する必要は認められない。通信条件、フレーム、通常コマンド、データ配置、タイムアウトの変更はない。Picoコードの即時修正は不要と判断する。

ただし、これはr1対応の量産完成を意味しない。OFF期間データの試験条件への反映、基準文書参照の移行、既存Open Issuesの設計回答、実NF55Gでの確認は必要。現行ATEアプリは骨格実装であり、Decode単体の実装と全Refresh/Query経路の完成は別である。

### 誤読を避ける点

- p.5のNAK理由3EH削除と、p.42 §13.9.2のエラーログID 33 `BOOT_CRC`は別。後者はr1でも残り、「アップデート時のみ」の備考も残る。ログIDを削除する根拠にはしない。
- p.37 §12.5.3の「アップデートリトライは失敗から1秒後に可能」は変更されていない。削除された「自動復旧が1秒以内に完了」と混同しない。
- p.39の既存クリア条件は変更なし。GET DATA2後のSET LIFEでBATT_DEG以外をクリアする条件、途中でAC OFFおよびPS_OFFした場合の例外、バッテリ異常ではクリアされない条件は残る。
- OFF期間データはD2であり、D3は寿命計算データ。D0ではoffset 62～91の30文字がOFF_PERIOD。

## 残る確認と試験

1. OI-22: 設計側にBOOT書込み中断からの正規復旧手順・適用FWを確認する。r1 §12.5.2冒頭は自動復帰可否に差があると述べる一方、各項ではBOOT/USERとも自動復帰不可に読める。Picoで独自の復旧処理を実装しない。
2. r1対応の実NF55GでPS_OFF中のOFFデータ更新を確認する。PS_ON中との比較、D0/D2値の対応、D2→SET LIFEのクリア条件と例外、BATT_DEG保持を確認する。時間や温度の丸め・測定分解能を考慮してATEが判定する。
3. 対応する製品FW版を識別し、既存Open Issuesの回答とともに、基準文書・ATE試験条件をr1へ整合させる。
