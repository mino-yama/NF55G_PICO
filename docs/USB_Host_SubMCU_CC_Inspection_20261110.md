## 判断と未確認事項

現在のType_C2はQR用SourceのCC条件を満たしていない。ファームをHostへ変えるだけでCC抵抗は切り替わらないため、QRを接続して受入成功とは扱えない。Type_C2は空のままとする。

Source用のRpは電源電圧と広告する供給電流に合わせて選ぶ。Sink用5.1kΩを0位置から1位置へそのまま移す、または0Ω短絡する変更は指示しない。Microchipの一般技術資料は、5Vプルアップの既定電流広告用Rpを56kΩ、1.5Aを22kΩ、3Aを10kΩとしているが、これは本基板への改造承認や値の確定ではない。供給能力・保護・基板実装を照合して決める。

また、CCのSource化だけではVBUS保護やD線のHost適合は証明できない。現物の電圧、電源経路、逆給電、過電流保護、QR公称230mAを含む電流余裕、D線プルアップ実装は未確認。Type_C1を7355のHostへ使う場合のCC／給電構成も別途確認する。

既存の計画・受入チェックリスト・資料台帳のType_C1「CC各5.1kΩはVSYS側」記載は、今回視認した原典と不一致。原典PDFは変更せず、USB-SUB-02として設計確認を求める。既存Open Issueは独断でCloseしない。

## 無負荷VBUS測定の準備（2026-11-10、ユーザー計測待ち）

ユーザーからテスターとUSB Type-Cブレークアウト基板があるとの回答を受けた。抵抗変更をせず、まず既存給電でType_C2のVBUSを測る。まだ測定結果は受領していない。

1. PCからUSBを抜き、QR・7355・治具UART・外部電源は接続しない。
2. USB給電元や他機器につながっていないブレークアウトをType_C2へ接続する。VBUS（5V）とGNDの端子名を確認する。端子や基板回路が不明なら写真で確認し、推測で接続しない。
3. テスターを直流電圧レンジへ設定する。黒リードはCOM、赤リードはV／Ω端子。電流測定端子・電流レンジは使用しない。黒プローブをGND、赤をVBUSへ、隣接端子を短絡しないよう無給電状態で固定する。
4. Type_C1だけを通信用USBケーブルでPCへ接続し、Type_C2ブレークアウト上のVBUS–GND電圧を読む。
5. 電圧値と、ブレークアウトに抵抗・LED・IC等が実装されているかを報告する。未実装／不明の申告は実測と区別する。測定後はPCのUSBを外してからプローブや配線を変更する。

これは無負荷電圧の確認であり、5V付近であってもSourceのCC設定、供給電流、保護、逆給電、QR動作の受入完了とはしない。電圧の合否許容差はここで独断に確定しない。

## 無負荷VBUS実測の回答（2026-11-10）

- ユーザー回答: 「VBUS:5Vを確認した。抵抗は変更なし、LED消灯」。直前に案内したType_C1 PC給電・Type_C2ブレークアウトでの無負荷VBUS測定に対する回答として記録する。
- 確認結果: Type_C2のVBUSは5V（ユーザー実測）。小数桁、計測器精度、負荷時電圧・電流は未記録。
- CC抵抗の変更なし。前回のCC1／CC2とも0=Sink位置実装、1=Source位置未実装という申告を継続する。VBUSの5V確認だけでSource設定完了とはしない。
- LED消灯を観測事実として記録。基板RGB LEDかブレークアウトLEDかは未確認。基板RGB LEDであればファームの駆動状態にも依存するため、消灯だけで給電異常・故障を断定しない。
- ブレークアウト上の抵抗／LED／ICの有無は、今回の回答では特定できていない。
- Source用Rp値・供給能力／保護・逆流・D線プルアップのHost適合は引き続き未確認。QRは未接続のままとし、Source化の変更手順は未確定。USB-SUB-01／USB-SUB-02はOpen継続。

### 次の測定: Type_C2 D−プルアップの予備確認（未実施）

PC USB・外部電源・他機器を全て外し、Type_C2ブレークアウトのD−と本体基板の3V3端子間を抵抗レンジで測る。赤黒を入れ替えた2方向の安定値を記録する。通電中は抵抗を測らない。D−端子が識別できなければブレークアウト写真で確認する。原典のR13=1.5kΩの現物確認を補助する測定で、並列回路・半導体の影響があるため、この測定だけで抵抗部品の有無・値・除去箇所を断定しない。変更・はんだ作業の指示ではない。

## 2026-11-11 訂正・後続条件（先のD線説明を読み替える）

原典の接続線とメーカーUSB-C専用コードを再照合し、本書のD+／D−とR13の説明を訂正する。正しくはD+=GPIO12／R12／DB_P、D−=GPIO13／R11／DB_N。R13=1.5kΩはD+のMCU側から3V3へのプルアップでありD−側ではない。DB_Nへの抵抗測定案内はR13確認として誤っており、測定中止のままとする。メーカーUSB-C版FAQにHost使用時のD+プルアップ撤去と位置写真あり。過去記録本文を履歴として保持し、今後は[Host回路条件Rev.0](USB_Host_SubMCU_Host_Circuit_Conditions_Rev0_20261111.md)の正しい接続表・変更案を参照する。
