# 開発用HOST RSTの分担・実装予定

記録日: 2026-11-22。案件: NF55G Pico試験治具。

## ユーザー指定

- 給電を維持した信号切断、および外部操作に必要なハードウェアは山田が検討する。
- コマンドで行うHOSTの通常RSTは2026-11-23に実装する予定。
- HOSTがハングしない前提で、開発を容易にするための明示コマンド操作を対象とする。

## 次回作業への引継ぎ

[開発用提案Rev.0](Development_Reset_Bootsel_Command_Proposal_20261122_Rev0.md)の通常RSTを次回の実装対象とする。まず既存双方向UARTを持つ測定器HOSTを対象に、管理受付・HOST再起動・親側の対象リンク再照合を実装する案を引き継ぐ。具体的なコマンド名・wire形式・期限は実装時に関連仕様と照合して詳細化する。

BOOTSELの給電維持・PC接続・信号切断回路は山田のハード検討範囲とし、その未確定を通常RST実装の開始条件にしない。BOOTSELコマンドの実装日は今回指定されていない。常時WDT監視・自動復旧・QR HOSTへの展開は今回の通常RST実装予定へ追加しない。

既存のCDC診断等の作業ツリー変更を保持し、実機版と候補を確認してから着手する。通常RSTの実装時はCode/Test/Docs/CHANGELOGを同時更新し、Host Unit/Mock試験を行う。実機再起動成立と機器通信の再開可否を区別し、過去の要求を自動再送しない。

## 今回の実施範囲

分担と予定の記録のみ。コード・FW・配線・Flash・実機状態の変更なし。Host Unit/Mock/実機試験は未実施。USB-HOST-RESET-01は実装・受入完了までOpenを維持する。本記録は作業予定であり、自動実行の予約ではない。
