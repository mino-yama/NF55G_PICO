## 現行の試験手順

事前にATEから `F?`、`R?`、`INIC?`、`TRS?` で計器設定を確認する。各セットで `TEST_START` → `EXT_QUERY 10000 MD?` → `EXT_QUERY 2500 ERR?` → `TEST_END` → 終了診断・SD・ログ欠落・通信状態の照会を実行する。次のセットは終了確認から1秒待って開始する。通信・記録の異常時は、既存の受入基準に従って停止し、試験記録を保全する。[従来の受入基準](CDC_Endurance_Acceptance_20261124_Rev0.md)

今回の受入範囲は上記のADC・20 V固定条件。過去のSCPIタイムアウトの技術的原因と、200 mVレンジでの400セット耐久は未確認。親Picoの `TEST_START` は最長11.218秒で、ATEの12秒待ちに対する余裕は約0.78秒。
