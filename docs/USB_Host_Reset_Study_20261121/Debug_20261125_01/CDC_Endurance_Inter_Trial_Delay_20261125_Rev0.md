# 耐久試験のセット間隔を5秒に変更

2026-11-25。実作業のセット間隔は約30秒。耐久試験では時間を短縮しつつセットの境界に待機を設けるため、試験ランナーの既定値を5秒にした。`TEST_END` 後の自己診断、SD状態、ログ欠落数、`COMM_STATUS?` の各確認が成功した時点から、次の `TEST_START` まで待機する。セット内のコマンド順序と応答期限は従来どおり。最終セットの後は待機なし。

設定は `--inter-trial-delay-seconds` で指定し、実行結果の `inter_trial_delay_seconds` に保存する。400セットでは待機が399回、合計33分15秒。前回のセット処理時間を目安にした全体の試算は約50分。受入条件と異常時の停止条件を引き継ぐ。 [試験ランナー](run_cdc_endurance.py)／[受入基準](../CDC_Endurance_Acceptance_20261124_Rev0.md)

模擬試験で400セットのすべての待機位置と回数、単発成功時の待機なし、タイムアウト時の停止と診断フレーム採取を確認した。5秒条件での実機試験は未実施。直前の実機試験ログは回収済み。 [回帰テスト](test_run_cdc_endurance.py)／[直前の実機試験](CDC_Endurance_Retest_20261125_1233_Rev0.md)
