# 交換HOST・電源確認 Rev.0

追加結果：新HOSTで7355 USBを外してRSTしてもINFO timeout。親GP12を低・高各30秒へ切り替え、親デジタル読戻しは0→1だが、ユーザー実測のHOST GP1は両区間3.28 Vで不変だった。PIO復元済み。[受信端の比較結果](Rx_Level_Comparison_Rev0.md)。

2026-11-28。通常外部給電時の交換HOSTについて、5V／VSYS―GNDと3V3―GNDの実測を依頼し、ユーザーより「3.3V/5.0V問題無し」と回答を受けた。ユーザー実測の申告値として3.3 V／5.0 Vを記録する。測定器・精度・リップル・起動時波形は未記録で、こちらによる直接取得ではない。

この結果を受け、定常の電源値が異常という前提では進めない。交換後の新HOSTで7355 USBを外してRSTし、管理情報応答が返るかを次に確認する。旧個体でのUSB切離し結果を、新個体の実績へ流用しない。基板間の信号コネクタは変更しない。

確認対象は新個体73AD3A60D10514E9、通常FW meter-host-relay-20261125.2。HOST情報応答が返れば、その状態（NOT_READY等）とUSB機器接続後の状態を比較する。現時点で電源以外の原因を確定したものではない。
