# HOST取り外し状態でのオシロ観測結果 Rev.0

2026-11-28。ユーザーより「GP12は波形有、GP13はHighのまま」と回答を受けた。このときHOSTは取り外しており、GP12の送信波形確認と、戻り信号のないGP13 Highを分けて扱う。GP13 Highだけを受信故障の証拠にしない。

PCからの情報要求反復は74回の完了後、次要求でATE応答0バイトとなり自動停止していた。[終了結果](result.json)／[反復原文](ate.jsonl)。観測後に`stop.request`も作成したが、それによる停止ではない。追加の治具IDNも0バイトだった。[停止後照会](after_stop.json)。原因は未確定で、HOST未接続timeoutとATEそのものの応答欠落を混同しない。

ユーザーが親PicoのRSTを1回実施後、IDN・IDLE・SD OK・drop0の正常応答を確認した。[親RST後の確認](after_parent_rst.json)。連続反復や製品指令は再開していない。

次はHOSTを元へ接続し、7355 USB未接続のままHOST GP1の波形到達を観測する。反復要求は10回に制限し、正しいHOST情報応答と管理timeout、ATE空応答を区別して保存する。親で波形があることだけではHOST端への到達を確定しない。
