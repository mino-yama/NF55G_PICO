# HOST取り外し・親GP12のオシロ観測

2026-11-28。ユーザーがHOSTを取り外し、親ポートをオシロ監視すると指定したため、明示管理INFO要求をATE COM7から反復する有限診断を開始した。

親保守USB COM6は接続申告後も未列挙だったため、準備したRAM上の0x55連続パターンは開始できなかった（`../scope_pattern_01/`は未実行）。代わりに現在接続可能なCOM7経由で、HOST_INFO? METERを反復する方式を明示して実行した。0x55固定波形ではない。

- 観測点：親GP12＝親Pico物理16番、GNDは親の物理18番など。
- 信号：既存PIOの115200 bps・8N1情報要求フレーム。HOST未接続のため約1秒の管理timeoutと次要求を繰り返し、送信バーストは約1秒周期。ビット幅の目安8.68 µs。約1秒周期の連続矩形波とは異なる。
- ATE IDNとCOMM IDLEを確認後、初回情報要求のERR:HOST_TIMEOUTを受信し反復開始を確認した。端子の実波形確認はユーザーのオシロ観測待ち。
- 上限600秒。終了要求はこのフォルダの`stop.request`を作成すると次の要求区切りで停止する。終了時の結果は`result.json`へ保存し、`ate.jsonl`は反復中も逐次保存する。
- 親FW・HOST FW・PIO設定は変更しない。NF55G製品指令、7355測定、R3受入は実行しない。

スクリプト：`scripts/scope_repeat_host_info_20261128.py`。波形観測後は終了結果を確認し、HOST未接続のまま無制限に要求を継続しない。
