# ADCMT 7355 ADCコマンド 試験・校正手順 Rev.0

2026-11-25。7355（製造番号246410099、FW A02）を現行の測定器USB HOSTからUSB CDCで制御。7351A／7351Eと共通のADCコマンドを使用する。

## 7355の設定

前面パネルで `MENU → 8 I/F → LANG → ADC → ENTER`。USBのクラスはCDCを選ぶ。ATEはCOM5から、設定は `EXT_SEND 2500 <コマンド>`、照会は `EXT_QUERY 2500 <コマンド>` で送る。各応答を待ち、次の照会まで前のコマンドから20 ms以上空ける。照会の計器原文はATE応答のHEXをASCIIに戻して確認する。

| 設定 | ADCコマンド | 照会と応答 |
|---|---|---|
| 直流電圧 | `F1` | `F?` → 7355は `F01`、7351A／7351Eの取説では `F1` |
| 連続測定 | `INIC1` | `INIC?` → `INIC1` |
| 即時トリガ | `TRS0` | `TRS?` → `TRS0` |
| ヘッダなし | `H0` | `H?` → `H0` |
| 自動レンジ | `R0` | `R?` → `R0` |
| 200 mV（シャント） | `R3` | `R?` → `R3` |
| 20 V（バッテリ電圧） | `R5` | `R?` → `R5` |
| サンプリング速度 SLOW2 | `PR4` | `PR?` → `PR4` |
| 7355のメモリ呼出解除 | `RN0` | `RN?` → `RN0,00000` など |

使用レンジを1つ選ぶ。実機試験では `SPN1`、`TRN1`（7355）、`TRD0`、`ST0` も設定して照会した。REF値や測定条件は既存の[3回路校正手順](ADC_Calibration_7355_Procedure_Rev0.md)を参照し、7355設定と測定指令には本書を使う。

## ATEの校正取得

試行開始 `TEST_START` 後、対象点の条件が安定してから回路別の測定指令を送る。末尾 `MD?` がADCコマンド経路を選ぶ。Picoは `F?`、`INIC?`、`TRS?`、`RN?` を検証する。最初の `MSR?` で既存の測定完了フラグをクリアし、その後の `MSR?` でEOM（ビット8）を確認してから `MD?` を送る。指定タイムアウトは取得全体に適用する。

| 回路 | A点の測定例 | キャッシュ照会 |
|---|---|---|
| 放電電流 | `CAL_MEASURE_DISCHG_I A 4000 MD?` | `CAL_MEASUREMENT_DISCHG_I? A` |
| 充電電流 | `CAL_MEASURE_BATT_CHG A 4000 MD?` | `CAL_MEASUREMENT_BATT_CHG? A` |
| バッテリ電圧 | `CAL_MEASURE_BATT_V A 4000 MD?` | `CAL_MEASUREMENT_BATT_V? A` |

ATEが実測値を採用した後の `CAL_WRITE_<回路> A P1` と `AD_VERIFY_<回路> P1` は既存手順を使用する。取得原文、単位変換、キャッシュ、AD/ARの契約は既存のまま。末尾 `:READ?` は、7355のLANGをSCPIにした場合の既存入口。ADCモード中は `MD?` を指定する。

## 確認結果

- 単発設定 `INIC0` では、BUSと即時の両条件でEOM＝256を確認したが、`MD?` はタイムアウトした。[BUSの実機ログ](ADC_Command_HIL_20261125_170715_657992.json)／[即時単発の実機ログ](ADC_Command_HIL_20261125_170911_090412.json)
- `INIC1`＋`TRS0` の連続・即時測定では、R0で `+08.12683E+00` V、R5で `+08.12680E+00` Vを3回取得。R3で同じ約8.127 Vを加えたままの試験では、`+9.999999E+37` を3回取得した。200 mV以内の有効入力での実測は未実施。[R0実機ログ](ADC_Command_HIL_20261125_171002_094360.json)／[R3・R5実機ログ](ADC_Command_HIL_20261125_171023_416471.json)
- 親Picoへ取得モジュールを配備し、COM5からBATT_Vの測定とキャッシュ照会を実行。R5で8.12679 V、R3でオーバーレンジと旧キャッシュの失効、R5へ戻して8.12681 Vの再取得を確認。取得は1.47〜1.56秒。COM22の応答原文でDCV・トリガ・呼出解除・新規EOM・測定値の順を確認。試行終了とログ破棄0件を確認。AD／ARは送信していない。終了時はADC、DCV、20 V、連続・即時測定。ホスト単体／Mock回帰548件成功。[校正取得実機ログ](ADC_Command_HIL_20261125_171253_291491.json)／[配備・復元用ハッシュ](integrated_20261125_171200_152678/manifest.json)

## 7351A／7351Eへの適用範囲

対応表のDCV設定・レンジ指定などは両機種の取扱説明書で照合した。7351A／7351Eの標準USBは取説上ADC計測器USBドライバを使い、同取説の `MD?` はRS-232用。現行治具の7355用USB CDC HOSTで7351A／7351Eを接続して測定できるかは未確認。7351A／7351Eでは実機と接続方式に合わせてADCコマンドの送信と測定データの受信を検証する。

- [7355取扱説明書 §6.4、§6.8](../../../reference/ADCMT_7355_20261104/7355-ope--foa-00000201a00-e.pdf)
- [ADCMT公式サンプル](https://www.adcmt.com/download/sampleprogram)の7355 USB CDC ADC版。取説のADCコマンド表は `MD?` をRS-232／LANと記載。USB CDCでの連続測定は公式サンプルと今回の実測を根拠とする。
- [ADCMT 7351A/E取扱説明書 §6.4、§6.7](https://manualzz.com/doc/68262871/adcmt-7351a--7351e-operation-manual)／[ADCMT公式USBドライバ案内](https://www.adcmt.com/download/usbdriver)
