# 初期校正値の復元可否

2026-11-25。接続中の製品が `S1.14B`／UNIT `000001` であることをD5で照合し、ADを送らずにARで現在値を再取得した。変更前に保存したARと照合すると差があるのは以下の2点。他8点はADC・REF8ともに一致した。 [変更前の控え](baseline.json)／[現状のD5・AR原文](19_restore_precheck_ar.log)

| 校正点 | 変更前 ADC / REF8 | 現在 ADC / REF8 |
|---|---|---|
| BATT_V P1 | `2663` / `00000008` | `0` / `00000008` |
| BATT_CHG P1 | `2292` / `00000001` | `1` / `00000003` |

この実機のARはREF8を整数で返し、変更前の小数値は保存済みARから特定できない。また、ADはその時点のADCを製品側で記録するため、元のADC値を送信引数に指定できない。比較に用いたレビュー版S1.15_r1の工場初期値はBATT_V P1が11.0 Vで、当該個体の変更前ARが示した8とも異なる。実機の元データとして使用できる退避済みEEPROMイメージは今回の記録から確認できなかった。

復元書込みは未実施。変更前のEEPROMデータがある場合は個体と形式を照合して復元手段を確認する。元データが得られない場合は、対象の2点を所定の実入力で再校正する。

## 承認済みの整数値を書き戻した結果

ユーザーの承認後、同じ個体をD5で照合し、BATT_V P1に8.0 V、BATT_CHG P1に1.0 Aを書き込んだ。ADは各1回。各直後のARと最後の全10点を照合し、対象外8点は初回の控えから変更なし。親PicoのDATA／AR Cacheを失効させた。 [書込み・読戻し原文](20_restore_integer_refs.log)

| 校正点 | 書込値 | AD VALUE8 | AR REF8 | AD／ARのADC |
|---|---:|---|---|---:|
| BATT_V P1 | 8.0 V | `41000000` | `00000008` | 0／0 |
| BATT_CHG P1 | 1.0 A | `3F800000` | `00000001` | 1／1 |

整数REF8は変更前の控えと一致した。ADCは書込み時の値であり、変更前の2663／2292は復元していない。変更前の小数値は未特定。
