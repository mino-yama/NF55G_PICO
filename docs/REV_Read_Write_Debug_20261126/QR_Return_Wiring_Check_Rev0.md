# QR用HOST 戻り線の配線点検

2026-11-26。親Pico GP8（物理11番）からQR用HOST GP1/RXへの追加線を接続済みとユーザーから連絡。FW書込み前に配線から点検する。

## 通電前の点検

| 点検箇所 | 期待結果 | 実測 |
|---|---|---|
| 親Pico GP8（物理11番） ↔ QR用HOST GP1/RX | 導通あり | 導通あり（ユーザー実測） |
| 追加したGP8線 ↔ GP9線（物理12番） | 持続する導通なし | 持続する導通なし（ユーザー実測） |
| 追加したGP8線 ↔ GND（物理13番） | 持続する導通なし | 持続する導通なし（ユーザー実測） |

追加線は上記3項目の配線点検条件を満たした。

導通モードは両基板の無給電時に使用する。測定時は、USB給電と外部5Vの両方を切る。親の物理11番と親のGP11（物理15番）を区別する。 [配線表](QR_Arm_Candidate_Rev0.md#実機の準備状況)

## PCでの事前照会

COM5のUSBシリアル変換器は列挙された。COM6は列挙されず、COM5の治具ID・通信状態・SD状態・ログ欠落・測定器HOSTの各照会は応答なし。QR用HOSTのBOOTSELも見つからなかった。これらの観測だけでは、給電状態や追加線の導通結果を判定できない。

再確認時は親PicoのCOM6（USB個体ID `69F7D45962CFDFAD`）を列挙した。COM5の治具IDは `NF55G_PICO_FIXTURE,Rev.0`、通信はIDLE、SDはOK、ログ欠落は0。ユーザー実測後の再照会でも `HOST_INFO? METER` は `ERR:HOST_TIMEOUT`。測定器HOSTの状態と今回のQR配線作業の関係は未確認。今回の点検でFW書込みやGP8の駆動は行っていない。

既存のQR用HOST GP0/TX→親GP9経路では、保守USBで定期通知を3件連続受信した（連番333〜335、1,000 ms間隔、HOSTの欠落カウンター0）。採取時のスキャナー認識フラグは0。保守採取後に親Picoの通常処理を再開し、COM5でIDLEを再確認した。 [受信原文](qr_return_wiring_existing_rx.log)

追加線のUART送受信とスキャナー読取は次の実機試験で確認する。
