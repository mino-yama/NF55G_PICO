## 恒久対策の候補と確認点

現行の受信専用UARTでは、開始前に読み始めたデータと開始後に読み始めたデータが、同じ形式の完成フレームで届く。診断のHID受信数は約1秒間隔で得られるため、短時間の読取開始やスキャナー内部に滞留したデータも識別できるとは確認されていない。

双方向の候補配線は親Pico GP8→QR用HOST GP1/RX。物理経路を確認後、親の受付要求IDに対し、QR用HOSTが読取途中のデータを読み切って破棄し、ID付きの受付応答を返す方式を検討する。受付応答後にQR用HOSTが最初のHID報告を受けた読取だけを、そのID付きで親へ配信する。切断・期限・旧ID・再起動時は取得を無効にする。スキャナー内部でトリガー済みでもHID報告がまだ送られていない場合は、リーダー自身のトリガー制御や受付応答後にスキャンを開始する運用も合わせて確認する。
