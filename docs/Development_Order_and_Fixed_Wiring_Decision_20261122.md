# 開発順序の採用・23日固定配線化

記録日: 2026-11-22。案件: NF55G Pico試験治具。

## ユーザー決定

直前に提示した手順で進める旨のユーザー回答により、次の開発順序を採用する。

1. 測定器HOSTの情報照会・通常RSTと現在の先行デバッグ。
2. ADC測定取得・CacheのATE接続。
3. AD書込み・AR読戻しと製品FWの小数扱いの実機確認。
4. AD個別照合。
5. QRの正式ATE読取り・Cache・SS書込み先指定・明示書込みと照合の検討/開発。

ADCの準備・独立開発は先行デバッグと並行し、組込みは先行デバッグ後。HOST BOOTSEL/QR HOST管理とD2/D3/D4専用Queryは後続の検討事項として維持する。未回答の通信契約・SS変換規則やOpen Issueを本決定で確定/Closeしたとは扱わない。

根拠: [未開発一覧・優先案](Undeveloped_Command_Inventory_20261122_Rev0.md)、[ADC/QR計画](ADC_QR_Integration_Plan_20261122_Rev0.md)、[小数実機試験計画](ADC_Decimal_Hardware_Test_Plan_20261122_Rev0.md)。

## 23日のハード作業と再開条件

2026-11-23、山田がブレッドボード配線から固定配線へ更新する予定。これは作業予定の申告であり、施工完了・動作確認済みではない。固定方法・具体的結線の変更内容は未確認。

更新後は無給電で現行ピン割付、TX/RX/GND、給電経路、対象基板を照合し、その実構成を記録してから起動する。QR経路GP8/9と測定器経路GP12/13を区別し、ピン変更があればFWとの対応を確認する。外部RESET配線の追加や給電維持PC接続が実現したとは推定しない。

起動時は個体/FW/boot世代・通信リンクを確認し、変更前の記録と比較できる単独確認から実機デバッグを再開する。配線更新でCDC受信停止が解消したとは先に判断せず、実機結果を記録する。ソフト開発は実機未接続でも進められる範囲を継続する。

今回の実施は方針/担当/引継ぎの文書更新のみ。コード・実機・配線への操作、試験再実行なし。
