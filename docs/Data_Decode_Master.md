# Data Decode Master
Revision: Rev.0

## 1. 共通 Decode Rule
- FLAG_HEX: 1 ASCII HEX nibble -> bit field
- NUM_HEX: ASCII HEX -> integer
- ASCII_TEXT: ASCII string
- Signed 8bit: ASCII HEX -> uint8 -> two's complement -> int8
- Scale は Decode 後に ATE 物理量へ変換する。

## 12. D2/D3/D4/D5
- D2 = OFF_PERIOD 30
- D3 = LIFE_CALC20 + EVENT_LOST1
- D4 = TIME12 + REALTIME50 + LIFE_DIAG30 + ACCUM70 + MFG50 = 212
- D5 = MFG50 + PARAM50 = 100

## 13. EB
20 chars = CURRENT10 + CHANGE10.
CURRENT と CHANGE は別保持。EB で STATUS Cache を更新しない。

## 14. EL/OL
82 chars = START_NO2 + 8 * RECORD10
RECORD = YEAR2 MONTH2 DAY2 HOUR2 ID2
No log = date 0, ID FF -> ATE 255.
Response START_NO must equal requested block start.

## 15. AR
140 chars = 5 systems * 2 points * (ADC6 + REF8)
Order:
DISCHG_I, BATT_V, ACDC12V_V, BATT_CHG, 12VOUT_V.
ADC = integer.
REF = raw8 + decoder-dependent value.
AR REF final wire format is Open Issue.

## 16. FD
Logical 32 bytes -> Wire 64 ASCII HEX.
ATE returns 64 ASCII HEX unchanged.
