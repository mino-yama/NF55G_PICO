# S1.15_r1 検証結果 — S1.13との差分・OI照合

作成日: 2026-11-18 / 管理名: S1.15_r1 / 方法: 提供ソースの静的レビュー

## 結論

通常測定の2点校正、DCIR中の充電電流、充電再開・満充電判定等に改善実装がある。ただし、既存OI全体が解決したとは判断できない。D0のCHARGE_END破壊読出し、AD直後の実行時係数反映、AD入力検証、BC=0の停止動作などは懸念が残る。特にEEPROM CRC対象の変更と、校正係数の単位変更に追随していない保護判定を優先確認する。

ソースで確認した実装と、仕様適合・実機改善の確認は別である。本報告によるOIのClose、Pico仕様変更、製品PASS/FAIL判定は行っていない。

## 優先確認事項（新規・再発見）

### S115-01 EEPROM互換性 — 高優先

事実: CRC検証長が834から835へ変更。eeprom.c:684で新版長のCRCを比較し、不一致なら出力を制御して無限ループへ入る（初期化呼出しはコメント）。

推測: 旧版が作成したEEPROMをそのまま引き継ぐ更新でCRC不一致となり、起動停止する可能性が高い。追加フィールドの初期化も必要。

未確認: 書込工程でEEPROM初期化/再生成を行うか、別の移行ツールがあるか。量産初品と旧版更新品を分けて確認する。

### S115-02 充電過電圧判定の係数単位 — 高優先

事実: init:120でgf_batt_v_coeffから1000倍が外れた。通常測定input:304はPoint2を含む式の最後で1000倍する。一方input:757のPRO_HIGH_V_CHG判定は `gf_batt_v_coeff * gu16_ad_chgout_v_now_ad` のまま。

推測: 保護閾値との単位・オフセットが不整合となり、従来の充電過電圧検出が成立しない可能性。通常測定式の修正だけをもって保護まで改善したと判断できない。

未確認: 設計上の単位、別経路の保護、実機検出。設計者に式を確認し、保護試験は適切な試験設備・条件で行う。

### S115-03 校正の即時反映・応答式と測定式の不一致

事実: 実行時測定式は2点オフセット補正へ変更されたが、AD成功応答のCALCは傾き×ADCのまま。実行時係数は初期化側で取り込む構造。

推測: AD直後のARには新記録が見えても、通常測定は旧係数を使用し得る。再起動後でもAD応答CALCと実測換算値が異なり得る。

未確認: 設計で求めるAD応答値の意味、係数再読込手順。OI-05/16/21を継続。

### S115-04 ARの小数情報

事実: 新旧ともfloatのpointをint32_tの整数HEX変換へ渡す。例として8.04は整数変換では8となり、float rawなら4080A3D7となる。過去調査対象と今回旧版の同一性は不明。

未確認: AR REFを整数・float rawのどちらとする設計意図。Picoが推測で復元・補正してはならない。OI-04へ今回のソース事実を追記する。
