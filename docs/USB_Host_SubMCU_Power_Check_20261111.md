# USB_HOST_SubMCU 電源確認・測定制約の追記

日付: 2026-11-11
対象: 継続中のWaveshare RP2350-USB-C受入案件

## 受領した事実

ユーザー回答: 「DB_N（DN1）ここを測定する事は不可能。本体3V3端子間 PInで3.3Vを確認した」。

- DB_N（DN1）は実物上の測定が不可能との申告。前回のDB_N–3V3間抵抗測定は中止し、追加の微細端子プロービングを求めない。
- 本体3V3ピンで3.3Vを確認したとの申告を、電源電圧の実測情報として記録する。測定基準点・小数桁・計測器精度は今回の回答で明示されていない。
- D−プルアップ抵抗値は未測定。3V3ピンの電源電圧から、R13の実装有無・抵抗値・D線のHost適合を推定しない。
- 前回のType_C2 VBUS=5Vという申告と合わせ、確認できた電源情報はVBUS 5Vと3V3ピン3.3V。供給電流・負荷時変動・逆流／保護は未確認。

## 手順の扱い

前回提示した微細なDB_N（DN1）への測定は以後必須手順としない。測定できないことは、部品未実装・断線・基板異常を示すものではない。部品の取り外し・配線追加を測定のために求めない。

D線プルアップのHost用処置は、保存済み回路図、メーカーの基板別手順、部品位置の確実な対応付けに基づき検討する。回路図上のR13=1.5kΩという情報と、現物の実装確認は分ける。実測できないことを理由に、R13除去やCC抵抗移設を独断で指示しない。

QR用Type_C2のCCは、最後に確認できた状態が両方0=Sink位置実装、1=Source位置なし。ユーザーから変更完了の回答はない。QR接続受入は、CC Source化とD線・給電構成の確認待ちを継続する。

測定結果と測定制約を文書化し、USB-SUB-02へ追記。コード・ファーム・基板変更、機器通信、実機テストは実施していない。Host／Mockは記録のみの変更のため再実行していない。USB-SUB-01／USB-SUB-02はOpen継続。過去の記録・原典を上書きしない。

## 後続調査によるD線説明の訂正と給電指定

R13はD−ではなくD+（GPIO12側）の1.5kΩプルアップ。DB_NはD−=GPIO13側であり、DB_Nの測定不能をR13確認に結び付けない。再測定は要求しない。ユーザーから、デバッグはPC給電、機器使用時は外部5Vアダプタ→Expander分岐で追加基板へ1Aまで供給可能との指定を受領。[Host回路条件Rev.0](USB_Host_SubMCU_Host_Circuit_Conditions_Rev0_20261111.md)へ部品変更案と給電の切替え・保護確認を整理。施工・負荷時測定は未実施。
