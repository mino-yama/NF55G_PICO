# USB HOST 中継基板 接続仕様・Codex引継ぎ

更新日: 2026-11-19

## 根拠と確認範囲

本資料は、2026-11-19のユーザー指示と、参照会話「USB HOST拡張接続整理」で提示された訂正内容を記録する。以下の「確認済み」はユーザーが指定した構成・方針を意味し、実機配線や動作の検証済みを意味しない。

参照会話: `6afe6a86-4f08-83ee-ba81-611b375d94ac`

## 確認済みの構成・方針

2026-11-19 ユーザー了承: Pico 2からQR用Waveshare RP2350-USB-Cと、外部測定器用Waveshare RP2350-USB-Aを使い分ける構成で合意。以下の役割分担を現行方針とする。

```text
Pico 2 ⇔ Expander ⇔ 中継基板
                    ├─ Waveshare RP2350-USB-C ─ USB HOST ─ QRリーダー
                    └─ Waveshare RP2350-USB-A (WAVESHARE-30274)
                           USB-C: 開発用接続
                           USB-A: HOST ─ ユーザー準備ケーブル ─ 外部測定器USB-B
                           給電: 外部電源

Expander CN
  ⇔ 秋月電子117585 ピンソケット
  ⇔ ADA-5200（8588、PiCowbell Proto）
  ⇔ はんだ付け配線
  ⇔ USB HOST各基板
```

上図は接続経路を示す。ピン対応表や電気回路図ではない。

| 項目 | 指定内容 |
|---|---|
| メインコントローラ | Raspberry Pi Pico 2 |
| 拡張側 | ExpanderのCNから中継基板へ接続 |
| 中継用ピンソケット | 秋月電子117585。Raspberry Pi Pico用20Pピンソケット、リード長3.2mm、左右セット（1セット） |
| 中継基板 | ADA-5200（スイッチサイエンス商品番号8588、PiCowbell Proto） |
| 接続方法 | Expander CNから117585のピンソケットを介してADA-5200へ接続。ADA-5200からUSB HOST ×2へはんだ付け配線 |
| QR用USB HOST基板 | Waveshare RP2350-USB-C。既存QR用基板 |
| 外部測定器用USB HOST基板 | Waveshare RP2350-USB-A、商品コードWAVESHARE-30274 |
| 外部測定器との接続 | Host基板のUSB-Aからユーザー準備ケーブルで外部測定器のUSB-Bへ接続 |
| 外部測定器用Hostの開発端子 | USB-C |
| 外部測定器用Hostの給電 | QR用と同じ外部電源を共用。既存記録上は多摩電子工業DC5V/2.4A（申告値）。総負荷・分岐保護・配線容量は受入確認 |
| ケーブル | ユーザー準備。型式・結線は現物確認 |
| RESET | 中継基板にRESET信号あり |
| 中継基板の役割 | USB HOSTとPico間の接続位置・配線を明確にする目印。ハード設計およびデバッグ時の説明を補助する |
| 使用対象 | 次に開発するUSB CDCと、開発済みQRのPico側ポート接続 |
| 変更しない項目 | 既存GPIO割当、通信制御方式、ファームウェア |

## 部品番号の訂正

過去の会話で記載された **C-17585は誤り**。正しい部品番号は **117585** とする。別部品として扱わない。
更新前のローカル引継ぎ文書ではC-17585の記載は見つからなかったため、訂正履歴としてここに明記する。

## 未確認事項

- Expander CNの具体的なCN番号・ピン番号と接続先の対応。
- 117585、ADA-5200、QR用USB-C Host、外部測定器用USB-A Hostの具体的なピン番号・配線位置。
- ユーザー準備ケーブルの型式・結線、および外部電源の端子・極性・容量・保護条件。
- QR用と共用する外部電源の実負荷時電流・電圧余裕、外部測定器を含む同時負荷での分岐・配線の受入。
- RESET信号の具体的な接続ピン・配線位置・接続先、および制御条件。

これらは [Open IssuesのUSB-INT-01](Open_Issues.md) で管理する。資料上の記録がないことだけで、実機の配線・作業が未実施とは判断しない。推測によるピン番号、信号の対応関係、RESET動作を追加しない。
