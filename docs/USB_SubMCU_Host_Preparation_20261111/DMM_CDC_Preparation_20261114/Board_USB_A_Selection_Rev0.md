## ユーザー指定で確定した方針

- 7355用の追加Host基板はWaveshare RP2350-USB-Aを使用する（ユーザーによる型番の明示で確定）。
- 追加基板のUSB-Aと7355のUSB-BをUSB A–Bケーブルで接続する。
- 2026-11-19追加指定: 商品コードはWAVESHARE-30274。基板のUSB-Cは開発側、USB-Aは外部測定器側とする。接続ケーブルはユーザーが準備し、給電は外部電源を使用する。
- QR用と7355用は別基板とし、親Picoへの独立双方向UARTを2経路用意する従来方針を維持する。
