# 中継リンク 実機受入手順 Rev.0（未実施）

2026-11-20 JST。対象は親Pico 2と外部測定器用RP2350-USB-A。QR用基板は変更しない。初回は識別通信の縦通しを確認し、レンジ検証は後回しにする。

## A. 配置前と無給電配線

1. 稼働中の試験がある場合は所定の終了/ログ保存を完了する。親とHostを無給電にし、PC USB-C、外部5V、7355 USB-B、診断UARTを必要な作業対象から切り離す。HostのUSB-C VBUSと外部5V/USB-A VBUSは共通なので二電源を直結しない。
2. 対象個体を照合する。Host chipidはBFCF2EDB84B0B37F。親の過去受入記録はunique_id 69f7d45962cfdfad/COM6だが、現在の列挙と実機IDを読取りで再確認し、COM番号だけで対象を決めない。
3. Hostは外部5V・7355を外し、PC USB-C単独でBOOTSELへ入れる。現行.5全Flashとmetadataを別名退避して照合後、配置用manifestの中継UF2 hashを照合しload -vを実行。書込み後infoでmeter-host-relay-20261120.1と対象chipidを確認する。自動電圧試験版.5のままで中継試験を起動しない。
4. 親は外部給電やHostからの給電/信号を切り離してPCへ接続し、実IDを照合。既存main.py/src一式と対象情報を別名退避し、[Parent配置一式](Deployment_Package/manifest.json)を同時配置する。staged configだけEXTERNAL_INSTRUMENT_ENABLED=True。機種や実ピンが不一致なら配置/給電へ進まず対応を確認する。配置後はファイルhashを照合する。
5. 両基板のPC給電を外して無給電にし、以下を現物ラベルと図面で照合して結線する。Expander CN/中継基板の物理端子番号・RESET結線は未確認なので、この表から推測して施工しない。

|親Pico 2|RP2350-USB-A Host|
|---|---|
|GP12 TX|GP1 RX|
|GP13 RX|GP0 TX|

親子間はMCU側の3.3V TTL UART。ATE側の既存RS232C端子とは区別する。Host GP12/13はUSB-A D+/D-であり、親GP12/13と同じ番号でも接続しない。SH-U05AのTXD/3V3/5V0は接続しない。RESET線は今回追加しない。

## B. 固定接続で起動

1. 無給電でHost USB-A→7355 USB-Bを固定接続。7355はBUS=CDC/LANG=SCPI、現在設定を記録する。初回IDNは測定入力やレンジ変更を必要としない。
2. PCのシリアルモニターは既存ATE用RS232C経路に接続する。**57600/8N1**、flow controlなし、ASCII、送信終端CR/LF/CRLFのいずれか、受信終端は既存設定のCR。COM番号は現在の列挙で特定する。COM22のHost診断用115200とは別の入口である。
3. 監視を先行してから外部5Vを投入。Host開発USB-Cは外したまま。親でexternal_errorがないこと、PIO1 SM4/5が使用できることを確認する。中継Hostは平文起動バナーを出さず、GP0にはX1フレームしか出さない。

## C. 最初の一要求

送信: EXT_QUERY 2000 *IDN?

期待: OK:EXT_RX:32:41444320436F72702E2C373335352C3234363431303039392C20204130320D0A とCR。これは現在の実個体ADC Corp.,7355,246410099,  A02とCRLFをHEXで表す。実応答が違う場合は原文を保存し、個体を照合してから評価する。別個体のIDを一致させるために応答を補正しない。

Host初期化途中のEXT_LINK_NOT_READY/AMBIGUOUS=0は未送信の拒否として記録する。端末へエラーが戻り、USB設定/接続条件を確認した後に、ユーザーが改めて明示要求を送る。Pico/Hostは要求を自動再送しない。

必要に応じ、次にEXT_QUERY 2000 :SYST:ERR?で機器エラー原文を取得する。キュー読出しが進むため結果を保存する。EXT_SENDはユーザーが選んだ既知の設定コマンドを一件だけ送り、OK:EXT_TXを機器の設定受理と解釈せず、別の明示Queryで確認する。今回の手順はレンジ切替やREADを自動送信しない。

## D. 異常と復帰

timeout・部分送信・切断・未要求データ等ではERR:EXT_<理由>:AMBIGUOUS=0/1を保存する。AMBIGUOUS=1は機器での実行成否が不明である。送信済み操作の取消成功を意味しない。

この初期中継版は故障状態を保持する。自動HELLO再送で故障を解除せず、Hostの再起動だけで計測器内の旧出力も消えたとは扱わない。新しい試行を開始する前に、未完了操作と古い機器応答が残らない状態を実機で確認し、親/Host/計測器の接続・起動を揃える。復帰操作の受入は正常系確認後の別工程とする。

## 受入の境界

実要求/応答原文、UF2/親ファイルhash、個体、接続、時刻、timeout/切断・dropを記録する。識別中継の成立、レンジ一致、測定精度、製品PASSを分ける。親/Hostソフトは製品合否を判定せず、任意応答を校正Cacheへ自動保存しない。NF55Gへの書込みやQRとの共存負荷は初回IDN受入に含めない。
