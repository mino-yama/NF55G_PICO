## 確認事実

## 比較の限界

今回提示ログには新しいCONF?や前面測定値の再報告は含まれないため、200V状態の根拠は直前のUP/CONF確認と維持依頼による。再接続が依頼どおりで基準源が一定なら低電圧比較として使えるが、基準源の精度/ドリフト/許容差や製品PASSは判定しない。0Vだった前試行は入力変更・無負荷の報告があるため、レンジによる異常値の証拠にしない。
