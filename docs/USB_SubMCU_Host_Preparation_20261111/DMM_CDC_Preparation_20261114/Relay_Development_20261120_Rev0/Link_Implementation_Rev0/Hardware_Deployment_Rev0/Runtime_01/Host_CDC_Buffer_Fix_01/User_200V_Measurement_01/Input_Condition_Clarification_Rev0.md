# 200V読出し時の入力条件 補足 Rev.0

2026-11-20。0V読出しに対する現在の前面/入力・配線確認の問いへ、ユーザーは「変わっている、現在無負荷」と回答。入力条件が前回の約2.911Vから変更されたという申告として記録する。

前回-2.91180Vと今回0.0000Vは入力条件が異なる試行であり、同じ入力に対する20V/200Vレンジ比較として扱わない。200Vレンジで同じ約2.9V入力を測定した確認は未実施。無負荷の具体的結線（開放/電源OFF/その他）は回答だけでは未確定で、無負荷なら必ず0Vになる等の判断はしない。今回の正常15byte/機器エラー0という通信観測自体は保持する。

次は約2.9Vの同じ直流入力をV/COMへ再接続し、200Vレンジを維持したまま前面値の安定を確認してREAD?一回→SYST:ERR?を実行する。入力を変更せず20V/200Vで比較できる状態を整える。Codexは追加設定/測定を送信せず、ユーザー操作手順のみ提示。

~~~text
EXT_QUERY 10000 :READ?
EXT_QUERY 2000 :SYST:ERR?
~~~

前面レンジを確認するためにUP/DOWNを追加押下しない。必要ならCONF?で状態を記録する。前面20V/旧RANG20読戻しの相違Issueは本回答でCloseしない。
