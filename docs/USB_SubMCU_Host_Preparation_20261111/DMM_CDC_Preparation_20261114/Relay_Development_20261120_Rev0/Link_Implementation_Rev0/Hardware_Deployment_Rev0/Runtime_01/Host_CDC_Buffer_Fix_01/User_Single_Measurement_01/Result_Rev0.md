## 確認事実

READ?の応答はOK:EXT_RX:15:2D30322E3931313830452B30300D0A。宣言/実長15byteで一致し、原文は-02.91180E+00とCRLF、DCV測定値は-2.91180V。SYST:ERR?は+0,No errorとCRLF、15byte。提示ログ上の1回の測定読出しが正常応答した。

負号についてユーザーは「前面もマイナス表示」と回答し、応答と前面の極性が一致。申告入力2.911Vは符号/精度の定義がなかったため、大きさの比較に限る。差は0.00080V（0.8mV）だが、許容差/確度/製品PASSや校正合格は判定しない。前面の全桁が-2.91180と同じかまでは今回回答に含まれない。
