# Codex直接固定入力・レンジ指定比較 結果 Rev.0

2026-11-20。ユーザーが電圧と配線を固定してCodexの送受信を依頼し、COM7を解放。初回AUTO単発-2.91185V成功後、同じ入力で3条件を各1回測定した。

## 確認事実

Host .3、COM7/57600 8N1、flowなし、DTR/RTS OFF。治具/7355 ID、DCV/連続OFFを照合し、IMM/トリガ1/サンプル1/遅延0を設定してQuery/OPCを各受信。AUTO OFFを読戻し確認後、RANG20→測定、RANG200→測定、AUTO ON→読戻し1→測定を逐次実施。各設定/測定の前後にCONF/機器エラーを保存。

|送信した設定|測定後CONFレンジ原文(V)|測定値(V)|機器エラー|
|---|---|---|---|
|:SENS:VOLT:DC:RANG 20|+1.999999E+02|-2.9118|0|
|:SENS:VOLT:DC:RANG 200|+1.099999E+03|-2.912|0|
|:SENS:VOLT:DC:RANG:AUTO ON|+1.999999E+01|-2.91186|0|

RANG20のCONFは測定前後とも+1.999999E+02、分解能+1.000000E-05。RANG200は前後とも+1.099999E+03、分解能+1.000000E-04。AUTO ON直後のCONFは+1.099999E+03を保持し、READ?後に+1.999999E+01/分解能+1.000000E-06へ変化。連続OFFで今回の自動選択が測定時に起きた観測として記録する。

各READ?は15byteで長さ/CRLF/数値形式が正常、機器エラーは全て0。3条件測定完了、自動再送なし。最終状態AUTO ON/DCV/連続OFF/IMM/トリガ1/サンプル1/遅延0。COM7解放済み、NF55G/電源/Flash操作なし。

## 判断・未確認事項

CodexからATE→親→Host→7355への設定指示と測定応答の取得を完了し、固定入力で約-2.912Vが各条件で得られた。基準電圧の精度/変動や許容差は不明で、製品合否や校正確度を判定しない。測定値へ倍率補正はしていない。

RANG20の約200V、RANG200の約1100Vという読戻しは実観測。メーカーのレンジ選択境界/指定値の意味や過去の前面表示との関係をこれだけで確定せず、USB-CDC-RANGE-01をOpen維持。Host中継に独自吸収しない。今回の前面値はCodexから直接観測していない。全受入（負荷/切断復帰等）の完了とはしない。

今回の変更は診断スクリプトと記録だけで製品コード/Flashは変更なし。全453件成功のFW .3を使用。
