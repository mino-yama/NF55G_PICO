# キー操作なしの現在レンジ読戻し 基準 Rev.0

2026-11-20。前面キーを押さずAUTO?/CONF?を送る依頼に対し、ユーザーがログを提示。Codexは提示HEXの復号のみで実機通信なし。

AUTO?は0（固定レンジ）。CONF?は36byteの正常な文字列、VOLT +1.999999E+01,+1.000000E-06と引用符/CRLF。レンジ読戻し19.99999V（20Vレンジ相当）、分解能読戻し1μV。この時点の機器読戻しは固定20Vに対応する。過去のRANG20直後のCONF約200Vとは取得時点/途中のキー操作が異なるため、以前のSCPI設定動作の確定や原因解明とはしない。

次はUPを一回だけ押し、表示に出た数値とAUTO?/CONF?を記録する。通常仕様では一段上の200Vへ移るため、読戻しが19.99999→199.9999へ変化するかを確認する。押下前後のQuery値で状態を区別し、一時表示がどの状態を示すかはその観測後に判断する。リモート状態でキーが効かない場合は追加キーを押さず状況を共有し、LOCAL操作による状態移行を別途確認する。
