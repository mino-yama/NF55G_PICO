# .3 固定20V設定のユーザー確認 結果 Rev.0

2026-11-20。ユーザーがシリアルモニターでAUTO OFF→AUTO?→RANG20→CONF?→SYST:ERR?を逐次送信し、ログと「レンジ20Vを確認した」を報告。Codexはポートを開かず提示HEXのみ復号した。

## 確認事実

AUTO?は0（AUTO OFF）。CONF?は36byteの完全な文字列で、復号は

"VOLT +1.999999E+02,+1.000000E-05"

とCRLF。数値は約200Vで、過去の999ET...のような書式崩れは今回ない。SYST:ERR?は+0,No error。前面レンジ20Vはユーザー確認済み。設定送信はOK:EXT_TXを返したが、読戻し値と前面のレンジ相違は残っている。

## 判断と未確認事項

前面20VとCONF約200Vの両方をそのまま記録。どちらかを正しいとして他方を換算/補正/読み替えしない。受信バッファ修正後の正常な形式でも相違が出たため、旧USB-CDC-RANGE-01をFIFO不具合だけで説明/Closeできない。メーカーのCONF/RANG動作・フルスケール表現・前面対応等は未確定。
