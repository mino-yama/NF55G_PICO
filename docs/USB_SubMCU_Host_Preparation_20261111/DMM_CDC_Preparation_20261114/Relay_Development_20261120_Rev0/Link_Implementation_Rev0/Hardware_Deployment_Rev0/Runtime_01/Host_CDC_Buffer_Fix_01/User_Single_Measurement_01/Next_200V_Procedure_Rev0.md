# 同入力での200Vレンジ確認 手順 Rev.0

直前の単発測定は-2.91180V、前面もマイナス表示とユーザー確認。現在と同じV/COMの約2.9V直流入力を維持し、以下を一行ずつ、応答完了を待って送る。

~~~text
EXT_SEND 2000 :SENS:VOLT:DC:RANG 200
EXT_QUERY 2000 :CONF?
EXT_QUERY 2000 :SYST:ERR?
~~~

前面が200Vへ切り替わったかを確認し、CONF原文/エラーを記録。前面200Vと機器エラー0を確認後、以下を一行ずつ送る。

~~~text
EXT_QUERY 10000 :READ?
EXT_QUERY 2000 :SYST:ERR?
~~~

ログと前面レンジ表示を共有する。CONFが別レンジ値でも独自換算せず原文を保持。測定値は-2.91180V付近との比較で、合否は判定しない。timeout時は再送せず中断する。これは手順作成でありCodexから設定/測定を送っていない。
