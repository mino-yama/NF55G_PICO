# 前面レンジ表示の解釈 補足 Rev.0

2026-11-20。ユーザーより「レンジボタンを押下すると、変わった後なのか、前なのかが不明」と補足。

## 原典で確認した事実

7355取扱説明書FOW-00000200A00の冊子4-3/PDF35ページ（4.1.1.4）、冊子4-19/PDF51ページ（4.2.2）をテキスト抽出とページ画像で確認。UPは測定中のレンジから一段上へ変更し固定、DOWNは一段下へ変更し固定、AUTOはオート/固定切替。押下そのものに設定変更の作用がある。

この該当箇所だけでは、ユーザーが見た一時的な数値表示が押下前/押下後/候補のどれを示すか明記を確認できなかった。その表示のタイミングを推測して現在レンジを確定しない。資料の図で恒常レンジ数値の読み方も確認できていない。

## 過去記録への補足

過去にユーザーが前面20Vと報告した事実は保持するが、今回の補足により、それが押下前の現在レンジを確定した情報とは扱わない。旧記録を削除/上書きせず、前面のレンジ読取りは未確認として訂正・追記する。正常なCONF?が約200Vを返した観測自体は変わらない。したがって前面と読戻しの実相違が確定したという扱いは保留する。USB-CDC-RANGE-01は人間確認なくCloseせず、確認前提を更新する。

単発測定原文-2.91180V、前面もマイナスというユーザー極性回答は今回の補足で変更しない。

## 次の確認

今は前面のUP/DOWN/AUTOを押さず、次を一行ずつ送って現在の機器読戻しを保存する。設定コマンドと測定は送らない。

~~~text
EXT_QUERY 2000 :SENS:VOLT:DC:RANG:AUTO?
EXT_QUERY 2000 :CONF?
~~~

必要ならこの基準値を記録した後、キーを一回だけ操作した前後のCONF/AUTO値を別々に記録して対応を確認する。機器からのCONF値だけを前面の独立証拠として扱わず、単位/指数を独自補正しない。今回はCodexから実機通信なし、原典と記録の補足のみ。
