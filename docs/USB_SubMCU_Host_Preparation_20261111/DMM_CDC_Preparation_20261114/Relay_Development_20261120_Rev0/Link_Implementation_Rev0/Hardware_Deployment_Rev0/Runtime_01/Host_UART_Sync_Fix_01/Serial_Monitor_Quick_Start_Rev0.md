2026-11-20時点の動作確認済み: Host meter-host-relay-20261120.2、親配置済み中継版、7355 serial246410099/A02。COM7のELECOM、57600bps/8N1、flow controlなし。ATE送信終端CR（CRLFも受理）。コード/開発用確認スクリプトのポートは終了時に解放済み。USB-UART監視器COM22はATE操作口ではない。Host外部給電中はHost PC USB-Cを接続しない。

1. COM7をシリアルモニターで開く。別アプリと同時に開かない。
2. *IDN?を送信しNF55G_PICO_FIXTURE,Rev.0を確認。
3. EXT_QUERY 2000 *IDN?を送信。今回の成功応答はOK:EXT_RX:32:41444320436F72702E2C373335352C3234363431303039392C20204130320D0A。HEXを復号するとADC Corp.,7355,246410099,  A02とCRLF。
4. ユーザーが確認する機器コマンドはEXT_QUERY <期限ms> <本文>（CRLF応答あり）またはEXT_SEND <期限ms> <本文>（応答なし）で指定。?から応答有無は推測しない。期限1〜10000ms、本文/応答192byteまで。機器本文の空白/カンマ/引用符/大小文字は保持する。次要求は前要求の応答完了後に送る。

OK:EXT_TXはUSBへの全送信完了であり、機器設定受理/レンジ一致/製品PASSを保証しない。timeout/切断等は自動再送しない。fault時の盲目的な再送/再bindは行わず、エラー原文を記録して復帰手順を確認する。USB未接続のLINK_NOT_READYは接続状態を見直す。
