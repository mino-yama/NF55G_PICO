# SH-U05A再ループバック結果 Rev.0

日付: 2026-11-14／USB Host SubMCUの外部給電UART無受信の切分け

## 実機結果

ユーザーが追加基板を切離し、SH-U05A単体のTXD–RXD短絡準備完了と回答した後に実施。

- COM22、VID:PID=1A86:5523、USB位置1-4.3を照合。
- 115200／8N1、フローなし、DTR／RTS=false。
- 112件すべて成功。送信5113byte／受信5113byte完全一致。
- ASCII・模擬35文字・制御byte・全256値・8種の長さ・100連番を確認。余分な送信前入力・末尾byteなし。
- 所要2.343秒、終了時COM閉。

この結果は変換器単体での送受信確認。追加基板のGP0出力・配線導通・外部給電起動を保証しない。変換器の故障を原因として確定せず、次は基板側の信号と給電条件を比較する。

## 次工程

1. 外部電源OFF、追加基板の外部5V線を物理的に外す。QR／7355なし。
2. SH-U05AをPCから抜き、テスト用TXD–RXD短絡を外す。UARTモード選択は維持。
3. 追加基板GPIOの0（GP0）→SH-U05A RXD、GND→GNDの2線だけを接続。変換器TXD／5V0／3V3は追加基板へ接続しない。
4. SH-U05AだけをPCへ接続し、追加基板のPC Type_C1は受信READY後に接続する。
5. PC給電での起動ログを先に再確認する。その後の外部給電比較はUART2線を動かさず、無給電で給電源だけを切替える。PCと外部5Vを同時接続しない。
