# 外部電源の電流制限に関する回答整理 Rev.0

日付: 2026-11-14

ユーザーは「電流制限付き電源は用意できている」と回答した後、型番・設定値の質問に対し「多摩電子工業 DC5V, 2.4A／電流制限はアダプタ内蔵」と再回答した。

## 確認できた申告

使用予定の電源は従来と同じ説明のアダプタであり、内蔵電流制限ありとの申告。別の設定可能な実験用電源が準備済みとした解釈は採らない。

## 未確認

- 正確な型番、電流制限の作動値・方式。
- 1A以下へ制限値を設定できる機能の有無。
- Expander追加5V枝の個別保護。

DC5V／2.4Aは出力定格の申告として記録する。制限作動値が2.4A、または1A以下とは断定しない。アダプタ内蔵保護がない、あるいは故障しているとも断定しない。

## 次工程の条件

既存作業票の追加枝1A供給枠に対する保護条件は未確認のまま。QR給電はまだ開始せず、追加枝に適したヒューズ等の保護方式か、設定可能な電流制限による評価経路を具体化する。保護部品の定格・時間電流特性・突入適合・配線容量の採否は別途確認し、1Aヒューズが厳密に1Aで即時遮断するという意味にはしない。

PC Type_C1と外部5Vは同時接続しない。現在の電源OFF状態は今回の回答では再確認していない。外部給電RST後に版・個体IDを取得できた実績は保持し、QR動作・保護動作の合格にはしない。
