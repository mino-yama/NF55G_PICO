# GP0修正後の観測と次の切分け Rev.0

日付: 2026-11-14

GP0修正と外部電源ONの申告後、COM22のUART受信を確認したが0byte。空ログはboot record missingで解析拒否。正常起動として扱わない。SH-U05A単体切分けへ移るため、対象採取スクリプトの実行プロセスだけを終了した。通常の180秒完走ではない場合がある。終了状態はobservation_before_loopback.jsonを参照。

次は外部電源OFF、SH-U05AのPC USBも外し、追加基板とのGP0／GNDを切離す。SH-U05A単体でテスト用TXD–RXDのみ短絡し、UARTモード選択は維持してPCへ接続。現在の変換器・ポート・接触でループバックを再確認する。過去の成功記録は保持。

原因未確定のためFW再書込み・別GPIOへの変更は行わない。基板・FW・配線・変換器の故障を断定しない。
