# QR評価前 HOST基板UART再確認準備

日付: 2026-11-14

ユーザーがQR試験の前に「もう一度HOSTとの通信」を指示。現qr-uart-20261111.1は追加HOST基板GP0 TX専用でコマンド受信処理がないため、今回はUART起動レコードのFW版・個体IDの再照合を行う。双方向の指令応答試験・親Picoとの正式UART通信ではない。

QR／7355／PC Type_C1を外した構成、外部5VとUART2線を使用する。電源ON状態なら受信READY後のRSTで取得、OFFならON後の受信を確認し必要時にRSTを案内する。QR接続済みの場合は外部電源OFFで先にQRを外し、その状態を申告してもらう。
