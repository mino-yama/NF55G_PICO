# 単体ループバック後のPC給電比較 Rev.0

日付: 2026-11-14

## 事実

- SH-U05Aの112件・5113byte送受信一致後、短絡を外し追加基板GP0→RXD／GNDを戻す手順に対し、ユーザーが準備完了と回答。
- COM22／115200・8N1でREADY後、外部5V線を外した状態でType_C1をPCへ接続する案内に対し「接続完了」と回答。
- 回答後の観測時点で受信0byte。信号線の写真確認へ移るため採取を終了。180秒の完走結果とは区別し、observation.jsonと、存在すればcapture_result.jsonを参照。
- 以前のPC給電時には版・個体IDの起動2レコードを取得した実績がある。現在の配線・接触・基板動作と同一と推定しない。

## 判断と次の切分け

PC給電でも未受信のため、外部電源だけに固有の問題と絞れない。変換器単体が通っても、基板GP0の出力・配線導通・実行中FWを保証しない。

次は追加基板PC USBとSH-U05A USBを外し無給電で、追加基板側の端子名、SH-U05A側のRXD／GND、両端間の配線とブレッドボード接点が分かる写真を照合する。Type_C1を上に見た場合、GP0は右列先頭の「0」。CC1／CC2の「0」ではない。USB端子の微細プロービングは不要。

写真照合後、必要ならジャンパ線の導通とヘッダ接触、GP0端子の電圧、Flashの版を順番に切り分ける。原因を断定してFW再書込み・GPIO変更・別部品除去は行わない。
