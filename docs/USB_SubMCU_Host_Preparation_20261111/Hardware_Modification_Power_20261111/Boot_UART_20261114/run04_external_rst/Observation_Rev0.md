# 外部給電RST後のUART受信・配線切分け Rev.0

日付: 2026-11-14

ユーザーが外部給電・UART配線維持のままRSTだけを操作したと回答。COM22／115200・8N1の受信待機後に操作を依頼した。回答後の確認時点でrawは0byte。これは観測時点の値であり、180秒の採取完了を意味しない。採取プロセスの最終値はcapture_result.jsonが作成された後に別途確認する。

直前の電源実測回答は5.00V／3.3V。原因は未確定。FW不良・給電不良・SH-U05A不良のいずれとも断定しない。

次は外部電源OFF、SH-U05AのPC USBも外した無給電状態で配線を確認する。追加基板GP0（基板表示「0」）→SH-U05A RXD、GND→GND。GP0はCC位置の「0」と異なる。変換器TXD／5V0／3V3は接続せず、テスト用TXD–RXD短絡は撤去、UARTモード選択ジャンパは維持する。

ブレッドボードの接点列・電源レール分断・ヘッダとの接触を含め、両端子名と配線が分かる写真で照合する。見えない端子や配線位置を推測して入替えない。PC Type_C1・QR・7355は外したままとする。微細USB端子へのプロービングは要求しない。

今回コード・FW変更、追加reset・書込みは行っていない。
