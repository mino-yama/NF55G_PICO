# 改造後 UART起動ログ確認 Rev.0

日付: 2026-11-14／SH-U05A COM23、115200・8N1、フローなし、受信のみ。

## 確認事実

- 電源投入時と、給電維持のRST後の2回を受信。各309byte、先頭00が1byte、その後に154byteのレコード2件。
- 両回とも元データの厳密UART解析はinvalid UART framing/truncated lineで不合格。
- 先頭00だけを除いた派生解析では、連番0のbootがqr-uart-20261111.1、連番1のboard_idがA06FEA01012EC137。2回の正規レコード部分は完全一致。
- 受信窓内でinit_failedレコードは見られなかった。ただしPIO初期化完了を示す成功レコードはこのFWにないため、エラーがないことだけでHost初期化成功とは断定しない。
- 各回は受信後5秒無通信で終了、COMを閉じた。SH-U05Aからの送信0byte。

## 推測・未確認

- 起動／reset時のTX線の状態変化が先頭00に関係する可能性はあるが、波形や別受信器による検証は未実施。FWが00を送信した／変換器不良／配線不良とは断定しない。
- 識別ペイロードは取得できたが、UART全体の厳密フレーミング受入は未完了。原文の先頭を黙って削除して合格にはしない。
- QR・7355は未試験、正式親子UARTも未受入。余分な起動byteの扱いは診断受信の同期処理・起動信号を別途検討する。
- 外部アダプタで電流制限ありとの申告はあるが、型番・制限値・Expander追加枝1A保護は引き続き未確認。次の外部給電・QR試験前に確認する。
