# QR接続・電源投入 初回採取 Rev.0

日付: 2026-11-14

Type_C2 QR接続、受信READY後の外部電源ONを案内し、ユーザーが「ONにした」と回答。受信結果はCOM22／180.062秒／0byte、送信0、ポート閉。

空ログのためFW版・個体ID・VID/PID・HID記述子は取得できていない。受信待機終了と実際の電源投入の厳密な時刻関係は確定しておらず、待受時間内に起動ログが出なかった原因をQR・FW・配線の故障に断定しない。QRのLED／起動音は今回回答に含まれないため未確認。

次はQR・外部給電・UART配線を維持し、待受上限600秒／最終受信後15秒無通信の別採取を開始する。READY後に追加HOST基板のRSTだけを操作してもらい、QRコードはまだ読ませない。PC Type_C1／7355は未接続を維持する。
