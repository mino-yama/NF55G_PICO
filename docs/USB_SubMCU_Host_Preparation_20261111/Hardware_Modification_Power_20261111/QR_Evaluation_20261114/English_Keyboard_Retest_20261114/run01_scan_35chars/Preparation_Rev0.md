# 英語キーボード設定 35文字QR再採取準備

日付: 2026-11-14

ユーザーがQRリーダーをAlt設定から英語キーボードへ変更。原文取得FW qr-uart-20261114.1へ実機書戻し・verify後、「試験開始」と指示。外部電源OFFで外部5V／GND・UART2線・Type_C2 QRを戻し、PC Type_C1と7355を外す手順で再採取する。

SH-U05A受信先行、115200／8N1、送信なし。全体600秒、最初の非ゼロHID報告後5秒無通信で終了。同じ既知35文字QRを1回だけ読む。英語設定の実HIDレポートとsuffixを確認し、Alt設定時のデータを流用しない。生データはscan_uart.rawへ保存する。
