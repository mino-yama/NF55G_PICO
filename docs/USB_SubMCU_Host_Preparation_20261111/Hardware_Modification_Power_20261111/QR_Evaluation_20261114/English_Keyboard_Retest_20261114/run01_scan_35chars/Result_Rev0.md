# 英語設定変更申告後の再採取 結果 Rev.0

日付: 2026-11-14

## 確認事実

- 原文取得FW qr-uart-20261114.1へ書戻し・独立verify済み。Alt専用C処理は現在のソース・実機FWから除去している。
- 受信READY後、ユーザーが外部給電中と回答。受信0byte観測後にRST＋3秒待ち＋既知35文字1回読取を案内し、完了回答を受領。
- COM22で60523byte、393レコード、HID388件（全8byte）、連番欠落・容量上限・エラーレコードなし、COM閉。
- 起動レコードはqr-uart-20261114.1／A06FEA01012EC137。QR VID:E851／PID:1001、63byte記述子は従来と同じ。
- HID payload388件は旧Alt設定時run05と全件一致。修飾値は00／04、04=Left Alt。最初は04 00 62...、04 00 00...を繰り返し、00065等のテンキー列という以前と同じ入力。

## 判定の範囲

ユーザーの「英語キーボードへ設定変更した」という申告と、実際に受信したHIDがAlt形式のままである観測を分けて残す。設定コードが正しく適用された／されていない原因は未確認。英語配列と出力方式が別設定という可能性も調査開始時の仮説であり、確定事項ではない。

今回のログを英語キーボード直接入力の合格とはしない。Alt専用FWを再導入せず、メーカーUSA設定コードを単独で再適用し、新たなrawで確認する。工場初期化や他の設定変更は案内しない。

## メーカー資料と次工程

通常の取扱説明書は概要中心だったため、公式キーボード設定PDFとオプションコードPDFを新規取得し、Manufacturer_Settingsへ原本・出典・hashを保存した。キーボード設定PDFはUSA／Japan／ALTの独立した3コードを掲載。全ページを描画して位置を確認し、USA部分のみをPDFから描画したUSA_Only_Manufacturer_Code.pngを作成した。バーコードの再生成や原PDFの加工は行っていない。

ユーザーにこのUSA単独画像だけを1回読ませてもらい、完了後に受信待機を再開する。35文字試験QRはその後の案内まで読ませない。QR接続・外部給電とUART配線は維持、PC Type_C1／7355は外したまま。
