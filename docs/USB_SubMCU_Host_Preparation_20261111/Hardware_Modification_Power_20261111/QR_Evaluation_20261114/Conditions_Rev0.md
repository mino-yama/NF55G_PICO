# QR単体評価 条件・ユーザー指定 Rev.0

日付: 2026-11-14／対象: 追加Waveshare RP2350-USB-C、A06FEA01012EC137

## 今回のユーザー指定

「FUSEを取り付けるのは難しい。機器の破損については、こちらで責任をもつので進めて下さい」と指示を受領。今回は追加ヒューズなし、申告済み多摩電子工業5V／2.4Aアダプタの内蔵保護を使用し、QR単体評価を進める。別の設定可能な電流制限電源があるとは扱わない。

既存作業票の追加枝保護条件に対する今回限定のユーザー指定であり、追加枝1A保護が確認できた、保護回路が不要、量産回路として受入済みという意味にはしない。原典・旧作業票は保持。USB-SUB-02をCloseしない。

## 初回試験範囲と順序

1. 外部電源をOFFにし、PC Type_C1・7355を外す。SH-U05AのGP0→RXD／GNDの2線は既にログを得た配線を維持する。変換器のTXD／3V3／5V0は接続しない。
2. 無給電でType_C2にQR（BCR-TC2D1BK）を固定接続する。初回はコードを読ませず、VID／PID・HID記述子・エラーの有無を先に取得する。
3. SH-U05A受信READY後、外部5Vを投入する。PC Type_C1は同時接続しない。先の外部給電では投入だけでUARTが出ずRST後に取得したため、必要時のみ受信状態を確認してRSTを別途案内する。
4. 受信原文を保存し、先頭NUL 1byteは明示オプションの警告付き解析で扱う。連番欠落・途中破損・記述子欠落・256件到達は拒否する。初回は受信後15秒無通信まで採取し、列挙記録を確認する。
5. 列挙・記述子を確認してから、短い1読取の原文取得へ進む。文字列デコーダ・35文字完全一致、7355・2 Hostはこの初回試験の成功範囲に含めない。

QRを接続したまま無給電で配線・向きを変更し、活線挿抜しない。異常発熱・臭い・電圧低下等があれば電源OFFとして記録する。起動UARTの先頭NUL原因と電源投入だけではログが出ない差は未解決として維持する。
