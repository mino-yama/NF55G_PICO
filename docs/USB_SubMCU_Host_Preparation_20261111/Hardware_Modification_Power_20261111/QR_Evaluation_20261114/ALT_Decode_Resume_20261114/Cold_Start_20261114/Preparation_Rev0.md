# 電源投入直後とRST後の比較 準備 Rev.0

2026-11-14。ユーザー観察「起動直後RSTしないと動作していない気がする」を対象とした同一USB Host案件の追加切分け。

第一段階: 外部電源OFF後にQRを外す。PC Type_C1・7355は外したまま。SH-U05AのPC接続とGP0→RXD／GNDだけ維持する。SH-U05AのTXD・5V0・3V3は接続しない。
次に受信を開始しREADY確認後、外部5VのみON。RST・BOOT・QR読取は行わず、10秒以上の起動ログを確認。必要なら別受信区間でRSTと比較する。
電源OFFで10秒以上待ち、QRの影響を除いた状態で自動起動を調べる。起動ログ未受信だけからCPU停止箇所・電源異常を断定しない。FW変更・書込みなし。
QRなしで確認後、必要に応じQRを接続した起動試験を別途実施。PC Type_C1と外部5Vの同時接続は禁止を維持する。
