# QR接続状態の電源投入試験 準備 Rev.0

2026-11-14。QRなしでは電源ONだけでboot/board_id出力を確認したため、QR接続条件と比較する。
ユーザーは外部電源OFFでQRをType_C2へ接続し準備完了と回答。Type_C1と7355は未接続、外部5V配線とGP0→SH-U05A RXD/GNDを維持。
受信READY後に外部電源のみON。RST/BOOTは押さない。まずboot/board_idとHID認識の有無を確認する。認識確認後、別指示でrun03のQR Aを1回読み取り、正常35文字一致を確認する。
UART115200/8N1、送信0。完成またはエラー後5秒無受信で終了、最大600秒。途中で無断RSTしない。FW変更なし。
原文を保持し、先頭NUL・初期化失敗・再起動も記録する。受信なしをCPU未実行と直結させない。
