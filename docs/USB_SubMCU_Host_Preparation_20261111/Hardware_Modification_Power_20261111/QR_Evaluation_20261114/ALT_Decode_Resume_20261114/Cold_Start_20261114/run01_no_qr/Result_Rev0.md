## 判断と限界

今回のQRなし条件では、RSTを押さず電源投入でFWのUART起動出力まで実行された。常にRSTが必要とは断定できない。
起動レコードはUSB Host初期化前に送信するため、これだけでHostタスクの継続稼働・機器接続時の自動認識を保証しない。QR接続状態の電源投入は別試験が必要。電源立上り・リセット・QR起動順等の原因は未確定。
FW変更・書込み・製品PASS/FAIL判断・Open Issue Closeなし。次は電源OFFでQRをType_C2へ接続し、再度電源投入前から受信してRSTなしで認識・読取を確認する。
