## 未確認事項・ユーザー観察

ユーザーは「起動直後、RSTしないとプログラムが実行されていない気がする」と申告。過去の電源投入とRST後の起動ログ差も継続課題。無受信だけからCPU未実行とは断定しない。
2回目起動が意図的RST／電源操作か、予期しない再起動かは未確定であり操作有無を質問中。給電低下・RUN信号・FW等の原因は未特定。
ソース上、UART版はUSB Host初期化より前に起動版と個体IDを送信する。ただし、その前にクロック設定があるため無受信だけで停止箇所は特定できない。
