# 固定接続・電源投入から連続読取 確認結果 Rev.0

2026-11-14。対象追加RP2350-USB-C A06FEA01012EC137、qr-fixed-20261114.1、QR BCR-TC2D1BK（取得profile E851:1001）。

## 今回の限定目標に対する結果

固定接続で「電源投入→RST不要→連続読取」の基本動作を確認した。

|試行|結果|証跡|
|---|---|---|
|電源投入第1回|RSTなし、起動後3606msでHID認識、A/B交互20回すべて35文字一致|[第1回](cold01/Result_Rev0.md)|
|電源投入第2回|RSTなし、3606msでHID認識、A1回35文字一致|[第2回](cold02/Result_Rev0.md)|
|電源投入第3回|RSTなし、3606msでHID認識、A/B各1回35文字一致|[第3回](cold03/Result_Rev0.md)|

3試行中3回の自動認識。今回の取得範囲でdecodeエラー・送信Queue drop・途中再起動なし。新Continuous版は64件FIFOを再利用し、旧生涯1024件停止を避けて7760 HID報告／20読取を処理した。
Host／Mock354件成功。実機配置前Flash2MB退避・load -v・独立verify済み。

## 判断の限界・残事項

- 起動待ち3000msを加えた候補で今回3回成功したという事実であり、原因の確定・全環境の起動保証とはしない。
- 10分以上の継続確認はエージェント追加の試験計画だった。ユーザーの待ち時間への指摘を受け、今回の限定目標の必須条件とせず省略。長時間試験成功とは記載しない。Hardware_Test_Plan_Rev0.mdの10分以上は当時の計画として残す。
- 先頭NUL1 byteは継続。原文UART全体の形式正常とはしない。
- 量産給電保護、正式親子UART／ATE／Cache／SS、要求と遅延読取の対応、7355／2 Host等は未完了。関連Open Issueは維持。Picoによる製品PASS／FAIL判断は行わない。
- ホットプラグはユーザー指定の固定運用範囲から除外済み。

実機受信は停止・COM22を閉じた。FWは配置済みのまま。新たな配線・電源操作は指示していない。
