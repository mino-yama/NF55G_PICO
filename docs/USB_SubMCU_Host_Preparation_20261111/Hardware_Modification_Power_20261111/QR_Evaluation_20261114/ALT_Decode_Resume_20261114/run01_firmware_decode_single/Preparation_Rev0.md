# Alt対応版 基板内35文字復元 単発採取準備

日付: 2026-11-14

ユーザー指定でAlt対応版qr-uart-20261114.2を再配置・独立verify後、外部電源OFFで外部5V／GND・UART2線・QR Type_C2を戻す案内に完了と回答。PC Type_C1／7355は未接続の手順。

受信READY後に外部給電。起動版と個体ID・QR列挙を確認し、同じ35文字試験QRを1回読む。HID原文と、基板が復元したkind12の35文字を取得して期待値と照合する。kind13はエラーとして扱い、受信終了条件の検出は合否判定に使わない。

600秒上限、復元結果またはエラー受信後5秒無通信で終了、送信なし。元rawを保存し、新旧試行の連番を混在させない。
