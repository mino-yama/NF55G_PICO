# 固定接続での確認範囲・ユーザー決定 Rev.0

日付: 2026-11-14

## ユーザー指示

「ここまでにして、マイコンは固定するから、電源投入～連続読取が出来れば良しにしよう」

抜き差し・再接続の実機切分けはここで終了する。基板とQRリーダーを固定接続し、電源投入からRST操作なしでQRを認識して連続読取できることを今回の確認目標とする。ホットプラグ復帰を今回の成立条件として追求しない。既存の未確認記録は削除せず、全機能の受入完了・Open Issue Closeとは区別する。

## 確認済み・残作業

- RST後の正常35文字単回・同一内容2回・異なる内容2回は実機で期待一致。
- 34文字不足・36文字超過・禁止文字の拒否と、その後の正常読取復帰も実機で期待一致。
- 固定接続での電源投入ではFW起動ログが出るが、QR認識なし。RST後は認識するため、電源投入から自動読取へ進む目標はまだ未達。
- 現診断版はログ1024件の有限記録で、確認は1起動2読取以内。長時間連続読取が成立したとは扱わない。継続運用向けの出力／バッファ方式と必要な連続読取検証は残作業。

## 次回の対象

固定接続での電源投入時のHost初期化・認識を調べ、RST不要の起動を実現する。続いて有限診断ログの制約を扱い、電源投入から連続読取を確認する。待ち時間の追加だけで原因・解決を断定しない。正式親子UART／ATEの未確定仕様は別途管理し、推測で変更しない。

今回は方針・試験範囲の記録のみ。追加の実機操作・FW変更・書込みなし。先頭NUL・量産給電保護・7355／2 Host等の既存課題は維持する。
