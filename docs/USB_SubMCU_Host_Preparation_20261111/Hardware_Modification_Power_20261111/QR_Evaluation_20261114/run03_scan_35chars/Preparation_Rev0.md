# 35文字QR 1回読取の採取条件

日付: 2026-11-14

試験QR: ../test_data/QR_35chars.png、原文はAbC-＋0を25個＋123456（35 ASCII文字）。ユーザー「準備完了」受領後、受信開始。外部給電・Type_C2 QR接続・GP0→RXD／GNDを維持し、PC Type_C1／7355は未接続。READY後にHOST RSTだけを操作し、3秒程度待って試験QRを1回だけ読む。

SH-U05AをVID/PIDで一意照合、115200・8N1、送信なし。起動・記述子・HID原文を保存。最初の非ゼロHID報告を検出後、5秒無通信で終了、上限600秒。停止検出は合否検査ではなく、原文を保持して後段で厳密解析する。再読取・連続読取は今回行わない。
