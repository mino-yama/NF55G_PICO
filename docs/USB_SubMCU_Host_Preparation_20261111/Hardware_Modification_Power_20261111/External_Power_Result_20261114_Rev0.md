## 今回の測定回答

|測定点|ユーザー申告値|
|---|---|
|追加基板5V－GND|5.01V|
|追加基板3V3－GND|3.30V|

直前に案内したExpander経由・QR／7355なしの外部給電手順への回答として記録する。今回の回答は電圧2点のみであり、異常発熱・臭い・電源OFF完了の回答はまだ受領していない。配線・給電構成を写真等で追加確認したものではない。

比較用: PC単独給電時の申告値は5.00V／3.30V。各電源レールの電圧情報として保持し、消費電流・突入・負荷時低下・保護動作・USB Host動作の合格とはしない。
