# 外部アダプタ申告・無負荷給電確認手順 Rev.0

日付: 2026-11-14／USB Host SubMCU改造後の継続作業

## 今回のユーザー回答

- 多摩電子工業、DC5V・2.4A。
- ヒューズ／電流制限はアダプタ内蔵との申告。
- 正確な型番・制限開始電流・保護方式・復帰方式は未確認。

2026-11-19追加指示: 外部測定器用HostにもQR用と同じ外部電源を共用する。従来のDC5V/2.4Aは申告定格として引き継ぐが、同時負荷時の電流・電圧余裕、Expander各枝の保護、配線・コネクタ定格は確認されていない。

5V・2.4Aは出力定格として記録し、電流制限開始値を2.4Aと断定しない。以前の「外部10W」申告と今回の定格表記は一致しないため、今回提示された5V・2.4Aを最新の申告として残す。別機種への変更か以前の概数かは未確認。

Expander追加枝に独立した1A保護があることは今回回答からは確認できない。アダプタ内蔵保護の申告を、追加枝1A保護の確認済みへ置換しない。QRに外部測定器Hostと外部測定器を加えた総負荷・突入・既存治具併用・量産保護の受入は未完了。

## 次のH2B 無負荷確認

1. 電源OFFで切り替える。追加RP2350のType_C1からPC USBを抜く。SH-U05AとのGP0／GNDの2線も一旦外す。QR・7355は接続しない。
2. アダプタをコンセントから外した状態で、Expanderの表示と回路図に基づき5V／GNDの取出し箇所・極性を確認する。VSYSや3V3を5Vと推測しない。表示を特定できなければ接続を進めない。
3. Expanderの5V→追加基板5V、GND→追加基板GNDを接続する。追加基板3V3へ5Vを入れない。ブレッドボードの電源レール分断・短絡・端子列を確認する。
4. アダプタからExpanderへ給電し、テスターDC電圧レンジで追加基板5V－GNDと3V3－GNDを測定する。異常発熱・臭い・不安定な電圧があれば切り離す。
5. 電圧2点と異常の有無を報告し、その後アダプタを切って無給電に戻す。電流レンジで電源間を測定しない。

PC Type_C1と外部5Vを同時接続しない。今回の無負荷確認をQR給電許可や保護試験合格とはしない。外部給電時は既存治具も通電する構成のため、既存治具ソフトの自動開始や製品への指令操作は今回行わない。
