## 次の作業

1. 56kΩ・1%を2個用意する。1005はユーザー推定の候補で、メーカーBOM確認済みとはしない。
2. 無給電のまま、用意した部品と実装パッドの適合を拡大確認する。不適合なら取り外し・実装を進めない。
3. 適合確認後、作業票Rev.0のH1に沿い、R18／R19／R13の撤去とR20／R21への各56kΩ実装を行う。施工前後写真を残す。
4. 施工確認後の初回は、外部5V・QR・7355・UARTを外したPC Type_C1単独の無負荷確認（H2A）。外部給電確認は別段階。

外部給電試験の前にアダプタ型番または電流制限値を確認する。5V・10Wの定格換算2Aと実際の制限開始電流は別の値。追加枝の1A保護の確認事項は継続する。

今回は申告記録の追加のみ。回路・コード・FWは変更せず、Host／Mockテストは再実行しない。改造・変更後通電・QR試験の合格を記録するものではない。
