# USB Host基板 改造再開記録 Rev.0

日付: 2026-11-14
対象: 追加Waveshare RP2350-USB-C（従来の対象個体 A06FEA01012EC137）

## 今回の確認

- ユーザーから「抵抗準備済み・全配線を外した」と回答あり。
- 質問対象は56kΩ・1%を2個、およびPC USB・外部5V・QR・7355・UART配線の切離し。
- 抵抗サイズは前回1005と推定。今回、寸法・実装パッドへの適合を実測確認したわけではない。
- 施工完了・変更後通電・UART版FW書込みの結果はまだ受領していない。

## 今回案内する施工

部品面を上、BOOT／RSTとType_C1を上、Type_C2を下に置く。無給電で施工前写真を残し、交換部品が実装パッドに適合することを確認する。

|部位|作業|
|---|---|
|Type_C2左 CC1「0」 R19|5.1kΩを撤去し未実装にする|
|Type_C2右 CC2「0」 R18|5.1kΩを撤去し未実装にする|
|Type_C2左 CC1「1」 R21|56kΩ・1%を実装|
|Type_C2右 CC2「1」 R20|56kΩ・1%を実装|
|メーカー位置写真で示すR13|D+の1.5kΩプルアップを撤去|

「0」「1」は抵抗値ではなく位置表示。R11／R12（27Ω）、Type_C1のR5／R6は維持。R10は原典で未実装のため、現物との差異があれば確認する。

R13は[メーカー位置写真](../../../reference/USB_Host_SubMCU_Host_Conditions_20261111/Waveshare_USB_C_FAQ_pullup.webp)と現物を照合する。特定できない部品を推測で外さない。施工後は未実装箇所・56kΩ実装・周辺部品・はんだブリッジ・パッド剥離を確認し、写真を残す。

**施工結果の確認までは無給電を維持する。** 次工程は外部5V・QR・7355・UARTを外したPC Type_C1単独の無負荷5V／3V3確認。外部アダプタの制限値と追加枝保護は未確認を継続し、QR負荷試験とは分ける。
