## 写真から確認できること・限界

- CC1／CC2の「1」側に部品が見える。抵抗値・公差・接合の電気的健全性は画像だけでは確定しない。
- 写真はブレッドボード上に実装した状態。右側のBOOT／RSTに近いType_C1にケーブルが挿されている。ケーブルのPC側接続・実際の通電状態は写真だけでは不明。
- R13撤去はユーザー申告として記録し、写真だけで全微細部品の施工合格とはしない。
- 変更後5V／3V3、USB認識、消費電流、UART版FW配置、QR動作はまだ今回の結果を受領していない。

## 次の確認 H2A

1. 外部5V・QR・7355・UARTを外す。ブレッドボードに5V／GNDやGPIOの意図しない短絡がないことを確認する。
2. PCからType_C1（写真右のBOOT／RST側）だけにUSB接続する。Type_C2（写真左）は空、外部5Vは物理的に切離す。
3. テスターのDC電圧レンジで黒GND、赤5V端子の値、続いて赤3V3端子の値を記録する。写真では上辺の右端から5V、GND、3V3の順。現物の端子表示を優先する。
4. 異常発熱・臭い・PC過電流表示があれば直ちに切離す。電流レンジで電源間を測定しない。
5. 電圧2点、異常の有無、PCへの接続状態を回答してもらい、その後にUSB認識確認へ進む。FWはまだ書き換えない。
