    The SH-U05A is the first product we have launched that supports both IIC, SPI and UART. The DSD TECH team has designed and released more than 30 different serial adapters. We are the world's most comprehensive supplier of serial adapters. Any of your serial adapter needs can be met here.


    Specification:

    Model: SH-U05A

    Main chip: WCH CH341F

    IIC/I2C Interface: SCL; SDA

    SPI Interface: MISO;MISI;SCK;CS2;CS1;CS0;

    UART Interface: TX,RX,GND;3V3;5V

    TTL Level: 3.3V

    USB interface: 2.0


    About indicator LED:


    IIC/SPI LED: When operating in IIC/SPI mode, this LED will be solid on.

    UART LED: When operating in UART Serial mode, this LED will be solid on.

    RXD LED:The data transmission indicator flashes when there is data from the USB UART port.

    TXD LED:The data receiving indicator flashes when the USB UART port receives data.


    List of supported systems:

    1,Windows xp,7,8,10,11

    2,Linux

    3,Mac OS

    You can download the driver directly from WCH's website


    Packing list:

    1 X SH-U05A USB to SPI/IIC/TTL UART Adapter

    1 X User Manual

    1 X 6 PIN DuPont cable
